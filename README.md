# ShipBash skills

The agent skill for [ShipBash](https://shipbash.dev), the AI QA team that tests your live web product from plain-language user journeys.

```
npx skills add dohooo/shipbash-skills
```

The `shipbash` skill ([`skills/shipbash/SKILL.md`](skills/shipbash/SKILL.md)) teaches a coding agent such as Claude Code, Codex or Cursor to work with ShipBash through its CLI, [`shipbash` on npm](https://www.npmjs.com/package/shipbash): find and change journeys and hooks, set when they run or run them now, read the results, and pull the evidence of any journey run, walk or Discovery, passed or failed. It leaves the commands to the CLI's own `help`.
